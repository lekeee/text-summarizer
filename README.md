# Text Summarizer

A web application for automatic summarization of text documents in Serbian.

The user can paste text or upload a document (TXT, DOCX or PDF), choose a summarization method and the summary length, and get an automatically generated summary together with basic statistics and a sentence importance map.

The project is developed as part of a bachelor thesis on automatic text summarization using natural language processing techniques.

## Tech stack

- **Backend:** Python, FastAPI
- **Frontend:** Vue 3, TypeScript, Tailwind CSS
